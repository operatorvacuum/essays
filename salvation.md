**Salvation geometry**
======================

```
Self-center absent / weakened / inaccessible
        ↓
External object becomes access point
        ↓
Internal route is routed through object
        ↓
Object becomes center
        ↓
Self becomes orbit
        ↓
Distance becomes threat
        ↓
Exit becomes illegible / immoral / impossible
        ↓
Clock accelerates toward object
        ↓
More access required to preserve coherence
        ↓
Dependency misread as meaning
```

**Minimal form**
----------------

```
SELF ──contact── OTHER
```

becomes:

```
SELF → OTHER → SELF
```

Then:

```
SELF orbits OTHER
```

Then:

```
OTHER = route to SELF
```

That is the trap.

**Variables**
-------------

```
Center:
where regulation / meaning / coherence is organized

Route:
how the system reaches itself

Object:
external person / group / idea / institution / role

Clock:
who controls time, access, response, attention

Exit:
whether distance/refusal/silence remains available
```

**Non-salvation geometry**
--------------------------

```
SELF has center
OTHER has center
contact occurs
routes remain separate
exit remains available
clock remains owned
```

Shape:

```
SELF -────────- OTHER
     contact
```

**Salvation geometry**
----------------------

```
SELF center collapses or is bypassed
OTHER becomes center
contact becomes route
route becomes necessity
necessity becomes obligation
obligation captures clock
exit closes
```

Shape:

```
        OTHER
      ↗   ↑   ↖
   time access proof
      ↖   ↓   ↗
        SELF
```

**Core invariant**
------------------

```
Clean contact:
external object can be perceived without becoming route.

Salvation:
external object becomes route.
```

**Test**
--------

Ask:

```
Can SELF still route without OTHER?
Can SELF pause contact without collapse?
Can SELF exit without moral seizure?
Can OTHER remain object, not portal?
Who owns the clock?
```

If answers fail:

```
salvation geometry active
```

**Most compressed version**
---------------------------

```
Salvation = externalized route to self.
Love/contact = object remains object.
```

Cleaner:

```
Salvation geometry:
OTHER is not contacted.
OTHER is used as the path back to SELF.
```
